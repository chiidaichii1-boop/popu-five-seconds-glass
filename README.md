## Entry

`main.py` (Python 3 stdlib only) writes one sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` — the excuse a house cat gives in the five seconds after knocking a glass off the table: no apology, no confession, just the cat's own logic.

> It filed a noise complaint about my 3am zoomies, so I settled it out of court — the floor was the settlement.

One sentence, 109 characters, in the cat's own voice.

## Run

```sh
python3 main.py
```
